Soal Limit AI

AI Gratis (bawaan) — pakai API key Gemini milik KaslyAI, dipakai bareng-bareng semua pengguna. Karena dipakai rame-rame, kuotanya kebagi habis kalau lagi banyak yang pakai bersamaan.

API Key Sendiri — kamu bisa tambah API key Gemini milik akun Google kamu, boleh lebih dari satu. Tiap API key Gemini gratis dari Google punya jatah kuota masing-masing, jadi makin banyak akun Google berbeda yang kamu buatkan API key-nya, makin besar total limit AI yang kamu punya — dan enggak berebut sama pengguna lain.

Bisa gonta-ganti pilihan ini kapan saja lewat menu Setting di dalam aplikasi.

Apa Itu API Key & Kenapa Aman?

Apa itu API key? API key itu semacam kunci akses pribadi dari akun Google kamu, khusus buat "memanggil" layanan AI Gemini. Ibarat kunci rumah — cuma bisa dipakai buat masuk ke jatah AI di akun Google kamu sendiri, bukan buat hal lain di akun itu.

Gimana cara kerjanya? Waktu kamu kirim foto struk atau chat ke asisten WhatsApp KaslyAI, sistem kami pakai API key itu di belakang layar buat minta AI Gemini baca dan catat transaksinya. Semua otomatis — kamu enggak perlu buka atau ketik API key itu lagi setelah ditambahkan.

Beda sama limit chat Gemini biasa. Jatah/limit API key ini terpisah total dari limit chat yang kamu pakai di app atau web Gemini biasa. Jadi sesering apa pun kamu ngobrol di Gemini langsung, itu enggak mengurangi jatah API key ini — dan sebaliknya, pemakaian lewat KaslyAI juga enggak mengurangi limit chat Gemini kamu.

Kenapa dibilang aman? Begitu ditempel, API key kamu langsung dikunci rapat di server dan enggak pernah ditampilkan utuh ke siapa pun — termasuk tim KaslyAI sendiri. Sistem cuma bisa "memakainya" buat manggil AI, bukan "melihat" isinya.

Kontrol tetap di tangan kamu. Bisa dihapus atau diganti kapan saja lewat menu Setting. Kalau dihapus, sistem otomatis balik pakai AI Gratis bersama supaya fitur AI-nya tetap jalan.
